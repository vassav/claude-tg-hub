# `/browser` в пульте + поддержка `@browser` из Telegram

**Статус:** дизайн утверждён 2026-07-27, проверен спайком.

## Задача

`@browser` в Telegram не срабатывает: это не команда движка, а @-упоминание, которое
разворачивает webview-композер панели VS Code. Сообщения хаба идут мимо композера — прямо в
stdin движка. Нужно: подключать браузер (`claude-in-chrome` MCP) к stream-сессии удалённо,
из Telegram.

## Проверенный механизм (спайк 2026-07-27)

Как это делает сам VS Code (extension.js 2.1.220, `ensureChromeMcpEnabled`):

1. Конфиг сервера — сам движок со спец-флагом:
   `{ type: "stdio", command: <claude-бинарь>, args: ["--claude-in-chrome-mcp"] }`.
2. Регистрация — `control_request { subtype: "mcp_set_servers", servers: {<вся карта>} }`
   в stdin движка. Движок сам спавнит процесс-мост и подцепляет инструменты
   `mcp__claude-in-chrome__*` (deferred, модель подгружает через ToolSearch).
3. Мост **автономен**: спайк (голый node-процесс, без VS Code) сделал initialize →
   tools/list (22 инструмента) → `tabs_context_mcp` и реально достучался до Chrome
   (создал tab group). VS Code в цепочке движок→мост→Chrome не участвует.

Важно: `mcp_set_servers` **заменяет весь динамический набор** серверов сессии (config-файлы
и плагины не трогает — проверено: плагины переживают регистрацию браузера панелью).
В ответе бывает карта `errors` (имя сервера → текст ошибки).

## Поведение

- **Пульт/команда.** Кнопка `🧭 браузер` в `controlPad` (`cmd:<id>:browser`) + bot-команда
  `/browser`, по образцу пятёрки `context|rc|limits|compact|interrupt`. Успех →
  «🧭 браузер подключён — пиши задачу обычным текстом». Повторно → «уже подключён».
  Ошибка/таймаут (8 c) → текст ошибки в TG. Только stream-сессии, как весь пульт.
- **`@browser` в тексте из TG.** Интерпозер/headless: подключить (если ещё нет), дождаться
  подтверждения, заинжектить сообщение с заменой упоминания на короткий инструкционный блок
  («инструменты браузера подключены; подгрузи `mcp__claude-in-chrome__*` через ToolSearch,
  начни с `tabs_context_mcp`»). Не удалось подключить → ошибка в TG, текст инжектится как
  есть, без блока.

## Архитектура

- **`panel/commands.mjs`** (общее ядро): `case 'browser'` в `createCommands.handle` — собрать
  `servers = { ...базоваяКарта, 'claude-in-chrome': bridgeConfig }`, отправить через
  существующий `issue('mcp_set_servers', …)`; разбор ответа (включая `errors`) в
  `onControlResponse`. Хелпер `chromeBridgeConfig(engineCmd, engineArgs)` — конфиг моста из
  команды движка (`node cli.js` → `[cli.js, '--claude-in-chrome-mcp']`; нативный exe →
  `['--claude-in-chrome-mcp']`). Новые deps от вызывающего: базовая карта серверов
  (функция) и конфиг моста.
- **`panel/interposer.mjs`** — совместное владение картой с панелью:
  - сниффит проходящие `mcp_set_servers` от панели → хранит последнюю карту (база мержа);
  - после нашего подключения дописывает `claude-in-chrome` в последующие карты панели
    (чтобы чужое обновление не снесло регистрацию);
  - если у панели браузер **был и пропал** — явное отключение из UI, уважаем, сбрасываем флаг;
  - если панель сама включила браузер — помечаем «включён» (и `/browser` ответит «уже»);
  - `@browser` в инжектируемом тексте → сценарий выше; инжект user-turn — только после
    control_response на нашу регистрацию.
  - конфиг моста — из своего argv (`interposer <node> <cli.js> …`).
- **`panel/headless.mjs`**: то же через общий `createCommands`; панели нет → база — пустая
  карта; конфиг моста из argv (`headless <claudeExe> …`); та же обработка `@browser`.
- **`hub.mjs`**: 3 точечные правки — кнопка в `controlPad`, `browser` в regex
  `cmd:`-callback'а, `browser` в списке пробрасываемых bot-команд.

## Тесты

Smoke-тесты по образцу существующих (`mock-mcp.mjs`, `smoke-*.mjs`), с мок-движком:

1. команда `browser` → движок получает `mcp_set_servers` с корректной картой, хаб — подтверждение;
2. `@browser` в тексте → сначала регистрация, после ответа — инжект с подменой упоминания;
3. карта панели: мерж после нашего включения; явное отключение панелью уважается;
4. повтор команды → «уже подключён», без второго `mcp_set_servers`.

## Вне скоупа

Команда отключения (есть в UI панели), CLI-channels-сессии (нет control-протокола),
рендер скриншотов в TG.
